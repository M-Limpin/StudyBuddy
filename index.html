How to use StudyBuddy
  1. Profile: Open the Profile tab, tap Edit Profile, and enter your name, course, student ID and photo.
  2. Tasks: In the Tasks tab, fill in the title, subject and due date, then tap Add Task.
  3. Status: Tap a task's colored badge to mark it Done (or back to Pending). A task becomes Late automatically when its due date has passed and it isn't done.
  4. Filter: Use the Pending / Late / Done / All buttons. The list shows Pending by default. Use the search box to find a task.
  5. Schedule: In the Schedule tab, add your class timetable (day + time + subject). Today's classes show automatically. Add one-time study sessions too.
  6. Delete: Tap the trash icon to remove a task, class or session.
  7. Reminders & AI: In Profile > Settings, turn on notifications, or add a Gemini API key to get AI suggestions based on your pending tasks.
  8. Saving: Everything is saved automatically in this browser — no login needed. Use Export Backup in Profile to keep a copy. Clearing browser data erases it.
